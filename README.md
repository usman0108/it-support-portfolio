# IT Support Portfolio

Welcome to my IT Support portfolio. I'm an aspiring IT Support professional with CompTIA Network+ and Security+ certifications, developing practical technical skills through hands-on labs.

This repository documents eight projects covering Windows administration, Active Directory, Microsoft 365, networking, troubleshooting and end-user support.

## Certifications

- CompTIA Network+
- CompTIA Security+

## Technical Skills

- **Windows Administration:** Windows 11, Windows Server 2022, user accounts and Group Policy
- **Active Directory:** User and group management, password resets, account lockouts and domain administration
- **Microsoft 365:** Microsoft 365 Admin Centre, Microsoft Entra ID, Exchange Online, Teams and SharePoint
- **Networking:** TCP/IP, DNS, DHCP, network connectivity testing and troubleshooting
- **IT Support:** Helpdesk ticketing, troubleshooting, issue documentation and escalation
- **Tools:** PowerShell, Windows Event Viewer, Command Prompt and Oracle VirtualBox

## Hands-On Projects

### 1. [Active Directory Helpdesk Lab](01-active-directory-helpdesk-lab)

Configured a Windows Server domain environment and practised common helpdesk administration tasks, including creating user accounts, managing security groups, resetting passwords and joining Windows 11 clients to the domain.

### 2. [IT Helpdesk Ticketing Lab](02-it-helpdesk-ticketing-lab)

Practised documenting, categorising and managing IT support incidents using a structured ticketing workflow.

### 3. [Microsoft 365 & Entra Administration Lab](03-microsoft-365-entra-admin-lab)

Practised Microsoft 365 user administration, licence assignment, multifactor authentication, password resets and collaboration tools.

### 4. [Windows 11 New Starter Deployment Lab](04-windows-11-new-starter-deployment)

Practised Windows 11 workstation preparation and onboarding activities in a simulated business environment.

### 5. [Network Troubleshooting Lab](05-network-troubleshooting-lab)

Used Windows networking commands and troubleshooting techniques to investigate connectivity and configuration issues.

### 6. [Microsoft 365 Troubleshooting Lab](06-microsoft-365-troubleshooting-lab)

Practised investigating Microsoft 365 user and service-related support scenarios.

### 7. [Active Directory File Permissions Lab](07-active-directory-file-permissions-lab)

Practised configuring and testing access to shared folders using Active Directory security groups and Windows permissions.

### 8. [Windows Event Viewer & Troubleshooting Lab](08-windows-event-viewer-troubleshooting-lab)

Investigated DistributedCOM Event ID 10010 using Windows Event Viewer and PowerShell. Diagnosed and resolved a Windows Update connectivity failure by configuring an additional VirtualBox NAT adapter.
