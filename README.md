# IT Support Portfolio

Welcome to my IT Support portfolio. I'm an aspiring IT Support professional with CompTIA Network+ and Security+ certifications, developing practical technical skills through hands-on labs.

This repository documents eight projects covering Windows administration, Active Directory, Microsoft 365, networking, troubleshooting and end-user support.

## Certifications

- CompTIA Network+
- CompTIA Security+

## Technical Skills

- **Windows Administration:** Windows 11, Windows Server 2022, user accounts and Group Policy
- **Active Directory:** User and group management, password resets, account lockouts and domain administration
- **Microsoft 365:** Microsoft 365 Admin Centre, Microsoft Entra ID, Exchange Online, Teams and SharePoint
- **Networking:** TCP/IP, DNS, DHCP, network connectivity testing and troubleshooting
- **IT Support:** Helpdesk ticketing, troubleshooting, issue documentation and escalation
- **Tools:** PowerShell, Windows Event Viewer, Command Prompt and Oracle VirtualBox

Configured a Windows Server domain environment and practised common helpdesk administration tasks, including creating user accounts, managing security groups, resetting passwords and joining Windows 11 clients to the domain.

### 2. [IT Helpdesk Ticketing Lab](02-it-helpdesk-ticketing-lab)
