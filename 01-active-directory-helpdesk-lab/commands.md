# Commands Used

## Network checks
```cmd
ipconfig
ipconfig /all
```

## Connectivity
```cmd
ping 192.168.50.10
ping DC01
```

## DNS
```cmd
nslookup helpdesklab.local
nslookup DC01
ipconfig /flushdns
```

## Group Policy
```cmd
gpupdate /force
gpresult /r
gpresult /h C:\gp-report.html
```

## System / identity
```cmd
hostname
whoami
systeminfo
```

Never include passwords or sensitive credentials in screenshots or GitHub documentation.
