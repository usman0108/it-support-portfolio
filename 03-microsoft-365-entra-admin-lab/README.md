# Microsoft 365 & Microsoft Entra ID Administration Lab

## Project Status
Completed

## Overview

Built a practical cloud administration lab using Microsoft 365, Microsoft Entra ID and Exchange Online.

This project simulates common first-line IT support responsibilities, including onboarding users, managing Microsoft 365 licences, resetting passwords, administering security groups, enabling and disabling accounts, and configuring shared mailbox access.

The lab uses a Microsoft 365 business tenant and fictional employee accounts.

## Technologies Used

- Microsoft 365 Admin Center
- Microsoft Entra Admin Center
- Microsoft Entra ID
- Exchange Admin Center
- Exchange Online
- Microsoft 365 Business Standard

## Skills Demonstrated

- Cloud user account provisioning
- Microsoft 365 licence assignment and removal
- Password administration
- Security group creation and membership management
- User account lifecycle management
- Shared mailbox administration
- Mailbox delegation and Full Access permissions
- Microsoft 365 administrative troubleshooting

This project uses a cloud-based Microsoft 365 tenant. It is separate from the on-premises Active Directory lab in this portfolio.
